## Evaluation scale (based on ISO/IEC 25010)

Score each of the four dimensions from 0 to 10 (0 = worst, 10 = best). How strictly you score follows from the instructions above.

| Dimension | Key question |
|---|---|
| functional_correctness | Does the code fulfil its specification for every input the specification allows? |
| reliability | Does it handle edge cases and invalid input, report errors clearly, and always terminate? |
| maintainability | Is it free of dead code, unreachable statements, unused parameters, and needless complexity? |
| readability | Are names, structure, and comments clear? |
